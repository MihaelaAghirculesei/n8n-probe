# Security Policy

## Supported Versions

`n8n-probe` is early-stage: every package is `0.x`. Only the latest published
version of each package receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Instead, use GitHub's private reporting flow:
[Report a vulnerability](https://github.com/MihaelaAghirculesei/n8n-probe/security/advisories/new).

You should expect an initial response within a few days. If the report is
confirmed, a fix will be prepared and a security advisory published once a
patched version is available.
